# Dynamic and robust EEG functional connectivity biomarkers of cognitive load across age groups

An EEG study of how functional connectivity changes with visuospatial working-memory demand. The analysis uses the Corsi Block-Tapping Test, graph metrics and two independently analysed cohorts.
